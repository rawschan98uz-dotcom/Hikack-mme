## → memory-bank/decisions.md

- **2026-10-10 Языки.** Своя маленькая система переводов (`src/i18n`), без vue-i18n: каждая фраза
  сразу на трёх языках, пропуск перевода = ошибка проверки типов. Значения в базе (источник лида,
  «Возврат: …» в комментарии) хранятся по-русски, показываются переведёнными. Узбекский —
  латиница с ʻ (U+02BB). По умолчанию язык — русский.
- **2026-10-10 Месяцы и дни недели** — свои названия на трёх языках (`month.*`, `weekday.*`),
  а не из браузера.
- **2026-10-11 Фирменный цвет — индиго** (#4F46E5, выбор владельца). Цвета — CSS-переменные
  `--c-*` в `src/style.css`; классы `fb-*` в Tailwind берут их оттуда.
- **2026-10-11 Тёмная тема** включается только по выбору (по умолчанию светлая), выбор хранится
  в браузере (`ui_theme`). Для стандартных цветов Tailwind (красные/зелёные метки) тёмный вид
  создаёт `app/frontend/tools/gen-dark-theme.mjs` → `src/styles/dark-palette.css`; `npm run build`
  запускает его сам. Печать всегда светлая.
- **2026-10-11 Главная под роль** (`api/v1/dashboard_focus.py`): деньги компании за день/месяц —
  только тем, кто видит график выручки (правило 2026-09-28: администратор не видит); долги и
  «кому позвонить» — тем, кто видит оплаты; учитель — только свои уроки, без денег.
- **2026-10-11 Фильтры** списков помнятся, пока открыта программа (вкладка браузера), и
  забываются при выходе из аккаунта. Ссылка со своими фильтрами важнее запомненных.
- **2026-10-11 Суммы** — одна функция `src/utils/money.ts` («1 250 000 сум», неразрывные пробелы);
  итоги оплат/расходов/снятий за период считает сервер по всему отбору, не по странице.
- **2026-10-11 Подъём/подсветка под мышью** — только у того, на что можно нажать.

## → memory-bank/troubleshooting.md

- **Chrome/Edge не знают узбекских названий месяцев** («2026 M09», «Tue») → свои названия в i18n.
- **Буква ʻ — это «модификатор» (\p{Lm})**: при сравнении введённого слова (подтверждение
  удаления) её надо выбрасывать вместе с апострофами.
- **«Сегодня» на странице посещаемости** брали по часам компьютера → теперь по Ташкенту
  (`todayIso()`); «вчера» считается от ташкентского «сегодня».
- **Папка `scripts/` в .gitignore** (исследования) — полезные скрипты класть в `app/frontend/tools/`.
- **Тёмная тема: новый цветной класс Tailwind выглядит светлым пятном** → пересобрать
  (`npm run build` сам обновит `dark-palette.css`).
- **Логотип: два SVG с одинаковым id градиента** — скрытая копия гасила видимую; у каждого
  экземпляра свой id.
- **Проверка в облаке:** временная SQLite в отдельной папке + `populate_all_data.py` для тестовых
  данных; настоящую базу не трогать.
